# 🛡️ Telegram Session Guard (حارس وسائط ومحتوى تيليجرام)

مشروع تطبيقي متكامل لهندسة علوم الحاسوب يجمع بين **Telegram Bot API** وبروتوكول **Telegram MTProto** لحفظ الوسائط المؤقتة (ذات التدمير الذاتي / View-Once) وفك قيود المحتوى المحمي في القنوات والمجموعات المقيدة.

---

## 🎯 فكرة المشروع والمشكلة الهندسية (Problem Statement)
* **المشكلة:**
  1. لا تتيح منصة تيليجرام لمستخدمي تطبيقها الرسمي خيار إعادة مشاهدة أو حفظ الصور ومقاطع الفيديو المؤقتة (View-Once / Self-Destructing Media).
  2. في القنوات والمجموعات التي تفعل خيار منع التوجيه والحفظ (`noforwards: true`)، يتم تعطيل زر النسخ والحفظ في واجهة التطبيق.
  3. بوتات تيليجرام الرسمية (Bot API) محصورة بمحادثاتها الخاصة ولا يمكنها بأي شكل مراقبة حساب المستخدم الشخصي أو استلام وسائط الـ View-Once.
* **الحل الهندسي:**
  بناء نظام هجين (**Hybrid Multi-Session Architecture**):
  - **واجهة تحكم (Bot Interface):** يتم من خلالها تسجيل الدخول برقم الهاتف ورمز التحقق (OTP) وكلمة مرور التحقق بخطوتين (2FA).
  - **محرك جلسات العميل (MTProto Userbot Engine):** يقوم بتشغيل عميل تيليجرام متزامن في الخلفية يرصد أحداث الرسائل الخاصة فور وصولها، ويلتقط بايتات الوسائط المؤقتة قبل انتهاء مؤقت التدمير، ثم يعيد توجيهها إلى "الرسائل المحفوظة (Saved Messages)"، كما يوفر أمر `/save` لسحب الوسائط المقيدة مباشرة من مسار البيانات الثنائي (Binary Stream).
  - **طبقة حماية مشفرة (AES-256 Fernet Layer):** يتم تشفير سلاسل الجلسات (`StringSession`) قبل حفظها في قاعدة البيانات المحلية بحيث لا يتم تخزين أي جلسة بنص صريح (Plain Text).

                       +-----------------------------+
                       |    مستخدم التيليجرام (User)  |

                                      │

                       +-----------------------------+
                       |   واجهة البوت (Bot Handler)  |

                       |      (AES-256 Symmetric)    |
                       +-----------------------------+

                       |       guard.db (مشفّرة)      |

                                      ▼
                       +-----------------------------+
                       |  محرك الجلسات (Userbot Engine)|

                       +-----------------------------+
                                      │
            ┌─────────────────────────┴─────────────────────────┐

  • تحميل بايتات الملف فوراً                  • جلب الرسالة بروتوكولياً بدون قيود

## 🚀 طريقة التثبيت والتشغيل (Setup & Run)

### 1. المتطلبات الأساسية
- مثبت **Python 3.10+** (تم اختباره بنجاح على Python 3.14).
- حساب تيليجرام.

### 2. تثبيت المكتبات
افتح الطرفية (Terminal) في مجلد المشروع ونفّذ:
```bash
pip install -r requirements.txt
```

### 3. إعداد المتغيرات (`.env`)
1. انسخ ملف `.env.example` إلى `.env`:
   ```bash
   cp .env.example .env
   ```
2. احصل على بيانات الاعتماد:
   - **`API_ID` & `API_HASH`:** ادخل إلى موقع [my.telegram.org](https://my.telegram.org) ➔ سجل دخولك ➔ اضغط على **API development tools** ➔ أنشئ تطبيقاً واحصل على القيمتين.
   - **`BOT_TOKEN`:** افتح تيليجرام وتحدث مع [@BotFather](https://t.me/BotFather) ➔ أرسل `/newbot` واتبع التعليمات لإنشاء بوتك والحصول على الـ Token.
3. افتح ملف `.env` واملأ القيم:
   ```env
   API_ID=12345678
   API_HASH=abcdef1234567890abcdef1234567890
   BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
   ```
   *(ملاحظة: اترك `ENCRYPTION_KEY` فارغاً في البداية؛ سيقوم النظام بتوليد مفتاح تلقائياً وعرضه في الشاشة).*

### 4. تشغيل البرنامج
```bash
python -m src.main
```

## 🎮 تجربة الاستخدام العملية (How to Use)

### الخطوة الأولى: ربط الحساب
1. افتح محادثة البوت على تيليجرام واضغط `/start`.
2. اضغط على زر **"📱 تسجيل الدخول برقم الهاتف"**.
3. أرسل رقم هاتفك مع الرمز الدولي (مثال: `+9647701234567`).
4. سيصلك كود التحقق من حساب تيليجرام الرسمي؛ قم بكتابته في البوت (يُفضل وضع مسافات بين الأرقام مثل `1 2 3 4 5`).
5. إذا كان حسابك مفعّلاً فيه التحقق بخطوتين (2FA)، سيطلب منك البوت كلمة المرور؛ قم بإرسالها.
6. ستظهر لك رسالة: `🎉 تم تسجيل الدخول وتفعيل الحماية بنجاح!`.

### الخطوة الثانية: اختبار حفظ الميديا المؤقتة
- اطلب من أي صديق إرسال صورة أو فيديو لك في المحادثة الخاصة مع مؤقت تدمير ذاتي (View Once / 5 ثواني).
- بمجرد وصول الرسالة إلى هاتفك، توجه مباشرة إلى **"الرسائل المحفوظة (Saved Messages)"**؛ ستجد أن البوت قد قام بحفظ الصورة كاملة بدقتها الأصلية مع تفاصيل المرسل ووقت الإرسال!

### الخطوة الثالثة: حفظ محتوى قناة مقيدة
- ادخل إلى أي قناة مشترك بها تمنع الحفظ والتوجيه.
- انسخ رابط المنشور المحمي (Copy Message Link).
- افتح **"الرسائل المحفوظة"** لديك وأرسل الأمر:
  ```
  /save https://t.me/c/1234567890/42
  ```
  أو:
  ```
  /save https://t.me/channel_name/42
  ```
- سيقوم النظام فوراً بسحب الفيديو/الصورة وإعادة إرسالها إليك حرة بدون أي قيود.

## 🎓 نقاط القوة للمناقشة مع الدكتور واللجنة الأكاديمية

عند تقديم المشروع ومناقشته، يمكنك التركيز على هذه المفاهيم البرمجية والهندسية:

1. **بروتوكول MTProto مقابل Bot API:**
   - توضيح أن واجهات برمجة التطبيقات العادية (Webhooks / HTTP Polling) عاجزة عن قراءة التشفير من طرف لطرف أو فحص التدمير الذاتي لحسابات الأفراد، وأن الحل الحقيقي تطلب استخدام مضاهاة عميل MTProto ثنائي.
2. **إدارة التزامن (Asynchronous Concurrency):**
   - كيفية استخدام مكتبة `asyncio` لتشغيل عشرات الجلسات (`TelegramClient`) في نفس الـ Event Loop دون الحاجة لفتح Thread مستقل لكل مستخدم مما يوفر استهلاك الذاكرة والمعالج.
3. **أمان البيانات وحفظ الجلسات المشفرة (Zero-Knowledge Architecture):**
   - توضيح أن سلاسل الجلسات الحساسة (`StringSession`) لا تحفظ بصيغة نصية واضحة في قاعدة البيانات لتفادي تسريبها في حال اختراق السيرفر، بل يتم تشفيرها باستخدام خوارزمية التشفير المتناظر **AES-256 (Fernet)**.
4. **التجاوز البروتوكولي للقيود (Protocol-level Bypass):**
   - شرح أن ميزة "منع الحفظ والتوجيه" في تيليجرام هي قيد على مستوى واجهة العميل (Client-side restriction) وليست قيداً تشفيرياً على مستوى السيرفر؛ لأن السيرفر مُلزم بإرسال بايتات الوسائط إلى الجهاز لكي يتمكن المستخدم من رؤيتها، وبالتالي استغل الكود وصول هذا الـ Stream لتحميله مباشرة.
